# Long-context DNA models do not use the allele

An audit of DNALongBench's eQTL task (eQTLP). Findings in brief:

- Variant-to-TSS distance alone beats every published model on the released split.
- On a distance-matched, chromosome-held-out rebuild (eQTLP-v2), no model beats a
  local-composition floor (AUROC 0.599).
- Swapping the alt allele for the reference changes AUROC by at most ~10^-3 for the CNN,
  frozen HyenaDNA and Caduceus probes, and end-to-end fine-tuned HyenaDNA.
- A matched ClinVar regulatory set gives the same null result.

## Not included (download or regenerate)

- **DNALongBench**: `git -c core.longpaths=true clone https://github.com/ma-compbio/DNALONGBENCH.git`
  (audited at commit `2c4060a`), plus its eQTL data in `data/eQTL/` (targets, hg38).
- **ClinVar** `clinvar.vcf.gz` and `variant_summary.txt.gz` (2026-09-06 release), from NCBI.
- **GENCODE v50** `gencode.v50.annotation.gtf.gz`.
- **Model weights**: HyenaDNA-medium-450k and Caduceus-Ph-131k, into `data/models/`.
- **Embeddings** (`data/**/*_emb/`): regenerate with `analysis/hyena_embed.py`,
  `analysis/caduceus_embed.py` and `analysis/variant_window_embed.py`.

## Environment

Python 3.12, torch 2.5.1+cu124, transformers 4.48.1 for the CNN and HyenaDNA. Caduceus
runs in a separate Linux env (Python 3.10, torch 2.2.0, mamba-ssm 1.2.0.post1). See
`analysis/caduceus_env_setup.sh`. On Windows, run Python with `-X utf8`.
